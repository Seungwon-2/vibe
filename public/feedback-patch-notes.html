플레이 피드백 반영 내역

반복 제보된 조작, 가시성, 코스 진행, 성능 문제를 반영한 v0.2.0 배포본입니다. 레이아웃과 색감은 이번 배포 후 사용자 의견을 더 모아 다음 수정에 반영합니다.

v0.2.0 배포 2026년 11월 13일 project02 자동 검증 통과 후속 의견 수집

이번 후보에 반영된 개선

이어하기와 메뉴 조작

이어하기 팝업을 닫을 수 있게 하고, Esc 일시정지 및 방향키·Enter 메뉴 탐색의 포커스 흐름을 보강했습니다.

로그인과 기록 안내

로그아웃 상태의 타이틀 진입 흐름과 스토리 모드의 브라우저 저장 처리를 점검했습니다. 기록과 랭킹은 여전히 이 브라우저에 저장됩니다.

코스 읽기와 회피 판정

장애물 실루엣, 낭떠러지 표현, 점프·2단 점프 회피 여유, 게이트 및 코스 생성 규칙을 보강했습니다.

난이도와 아이템 흐름

무한 코스의 후반 게이트 생성을 이어가고, 장애물·아이템 스케줄과 패턴 변주를 조정했습니다.

오디오

기본 음량을 낮추고, 사용자 입력 이후 배경음을 시작하며 음량 설정을 저장하도록 했습니다.

캐릭터와 성능

다섯 캐릭터의 모션 전환과 패시브 동작을 자동 검사하고, 긴 코스의 스케줄 생성을 최적화했습니다. 캐릭터 카탈로그는 후속 캐릭터 에셋을 추가할 수 있도록 유지했습니다.

피드백 20개 상태

#항목상태요약
1이어하기 팝업 닫기수정 확인닫기 선택과 팝업 회귀 테스트를 확인했습니다.
2로그아웃 화면 로그인 버튼수정 확인로그인 진입 흐름을 배포 후 확인한 기록이 있습니다.
3배경음 시작수정 확인사용자 첫 입력 후 재생하도록 했습니다. 자동재생 차단은 브라우저 정책입니다.
4기본 음량수정 확인낮은 출력으로 조정했고 사용자가 로컬 음량을 확인했습니다.
5게임 화면의 빈 공간후속 의견 수집현재 배포본으로 의견을 더 받은 뒤 화면 크기와 여백을 조정합니다.
6색감과 눈 피로후속 의견 수집현재 색감으로 플레이 의견을 받은 뒤 대비와 밝기를 조정합니다.
7장애물 가시성테마별 확인실루엣 개선과 자동 검증은 완료, 네 테마 실주행은 대기 중입니다.
8낭떠러지 표현사용자 확인화면 아래까지 표현을 연결했고 사용자가 확인했습니다.
9잠긴 캐릭터 치장 장착자동 확인잠긴 캐릭터를 상점 선택 목록에서 제외하는 테스트가 통과했습니다.
10캐릭터 패시브 효용체감 재확인패시브 기능 테스트는 통과했습니다. 밸런스 체감은 플레이 검토가 필요합니다.
11장애물 회피 판정실주행 확인충돌·점프 회피 테스트는 통과했으며 테마별 조작 확인이 남았습니다.
12후반 게이트 생성자동 확인50km 코스 생성 및 이어하기 점검에서 후반 게이트를 확인했습니다.
13스토리 저장 실패 오경고저장소 확인스토리 저장 회귀 테스트는 통과했습니다. 저장소 차단 환경 점검은 남았습니다.
14끊김 현상장시간 측정 대기스케줄 성능 벤치마크는 통과했습니다. 실기기 프로파일과 장시간 플레이는 대기 중입니다.
15캐릭터 점프·달리기 모션실주행 확인아틀라스와 전환 테스트는 통과했습니다. 현재 브라우저에서의 모션 체감 확인이 남았습니다.
16가속 아이템 효용체감 재확인배치와 지속시간 검증은 완료했으며 플레이 보상감 평가는 남았습니다.
17장애물 패턴 단조로움테마별 확인결정적 패턴 변주와 장거리 스케줄 검사는 통과했습니다.
18업적 이름 영어 코드 노출자동 확인한국어 이름과 미등록 ID 대체 표기를 테스트했습니다.
19Esc 일시정지수정 확인키보드 접근성 테스트와 사용자 조작 확인 기록이 있습니다.
20방향키·Enter 접근성수정 확인모달 포커스 흐름을 보강했고 사용자가 방향키 조작을 확인했습니다.

검증과 알려진 제한

이 문서는 배포된 v0.2.0의 패치노트입니다. GitHub Actions에서 전체 테스트 282개, 타입 검사, 린트, 빌드와 Azure 업로드가 통과했습니다. 레이아웃·색감 의견은 배포 후 수집하며, 네 테마 실주행과 장시간 프레임 프로파일링도 후속 확인 항목입니다.
  • Vite 번들 크기 경고가 남아 있습니다. 빌드는 성공했으며 번들 분할은 후속 최적화 항목입니다.
  • 온라인 공유 랭킹과 Cosmos DB 기록은 연결되지 않았습니다. 개인 기록·코인·해금은 브라우저 로컬 저장입니다.
  • 수동 QA 결과는 상세 피드백 검증표에 기록합니다.
