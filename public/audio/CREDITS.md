# Audio credits

Audio files under this folder were supplied for the Stella Runner prototype. The accompanying `music/README.txt` describes them as original procedural compositions and says the pack is for the prototype and internal sharing. The README also says BGM instrument timbres were rendered from TimGM6mb by Tim Brechbill under GPL-2.0; the SoundFont is not included. The individual audio author and permission to redistribute this pack outside the stated sharing context have not been independently verified.

## Background music

| File | Use |
| --- | --- |
| `music/title.ogg` | Title and non-run screens |
| `music/city.ogg` | Dawn City course |
| `music/forest.ogg` | Moonlit Forest course |
| `music/mine.ogg` | Crystal Mine course |
| `music/sky.ogg` | Cloud Skyway course |
