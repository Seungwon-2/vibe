스텔라 러너 파일럿 v0.1.0

현재 배포된 버전의 기능과 확인된 제한 사항을 안내합니다. 이 버전은 추가 플레이 테스트와 개선 의견 수집을 위한 파일럿입니다.

파일럿 테스트 버전 v0.1.0 2026년 11월 12일 project02 배포 확인 완료

이번 배포에서 확인할 수 있는 내용

로그인과 계정 정보

회사 Microsoft Entra 계정으로 로그인하고, 메뉴에서 제공되는 이름·계정 정보를 확인하거나 로그아웃할 수 있습니다.

러닝 액션 플레이

점프와 슬라이딩으로 장애물을 피하고 코인, 시간 보너스, 속도 부스트와 거대화 아이템을 활용합니다.

두 가지 플레이 모드

시간과 거리를 겨루는 끝없는 달리기, 테마별 코스를 완주하는 스토리 스테이지를 플레이할 수 있습니다.

캐릭터와 진행

캐릭터별 패시브 효과와 스테이지 진행 해금이 적용됩니다. 이어하기는 같은 브라우저 프로필에 저장된 런 상태를 복구합니다.

테스트 중인 저장 방식

로그인과 게임 기록은 현재 별도로 동작합니다. Entra 로그인은 회사 계정을 확인하지만, 런 기록·코인 지갑·해금 상태·이어하기는 이 브라우저 프로필의 로컬 저장소에 보관됩니다. 계정별 분리나 서버 동기화는 없고, 같은 브라우저 프로필을 사용하는 사람은 로컬 데이터를 볼 수 있습니다. 브라우저 데이터를 지우거나 기기·프로필을 바꾸면 기록은 이어지지 않습니다.
  • 온라인 공개 랭킹과 다른 직원의 기록 조회는 아직 제공되지 않습니다. 메뉴의 기록은 이 브라우저에 저장된 기록입니다.
  • 이어하기는 저장된 브라우저의 런을 복구하기 위한 기능이며 서버 동기화는 하지 않습니다.
  • 직원 이용 안내 보기에서 조작법, 아이템과 저장 범위를 확인할 수 있습니다.
  • 이 배포는 파일럿 테스트 단계입니다. 플레이 중 문제나 개선점을 기록해 다음 업데이트에 반영할 예정입니다.
