데이터베이스에는 400 RU/s 공유 수동 처리량이 설정됐습니다. Free Tier 잔여량에 따라 추가 처리량 비용은 $0부터 약 $23.36 USD/월까지 달라질 수 있습니다. 세금·할인·실제 사용량은 별도입니다.

금액은 사전 추정이며 실제 청구액은 Azure Cost Management에서 확인해야 합니다.

남은 배포 단계

  1. 회사 테넌트에 전용 단일 테넌트 Entra SPA 및 API 등록을 만들고 리디렉션 주소와 API 권한을 맞춥니다.
  2. Entra 등록 정보를 연결하고 Cosmos 접속 값은 Static Web Apps 관리형 API의 서버 전용 설정에 입력합니다. 비밀 값은 코드·문서·로그에 저장하지 않습니다.
  3. GitHub Actions를 Seungwon-2/vibe의 project02 브랜치와 연결하고 배포 토큰은 GitHub Secrets에 둡니다.
  4. 실제 앱 주소 접속, 로그인, API·랭킹 동작, GitHub Actions 자동 배포를 확인한 뒤 직원용 안내와 릴리즈 노트를 갱신합니다.

아직 확인되지 않은 항목: 앱의 실제 접속 주소와 배포 상태, Entra 인증, API 설정, 랭킹 기능, 실제 청구액. 이번 ARM 결과는 리소스 생성 성공을 확인하며 이 기능들의 동작까지 증명하지는 않습니다.
