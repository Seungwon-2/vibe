전체 미리보기

Bicep 빌드는 통과했지만, 무료 앱 할당량 오류로 ARM what-if가 완료되지 않았습니다. 정확한 리소스 추가 목록은 아직 승인 가능한 상태가 아닙니다.

다음 단계

  1. 다른 사용 가능한 승인 구독을 선택하거나, Standard 플랜의 반복 비용을 검토해 선택합니다.
  2. Cosmos 비용 범위와 배포 대상 이름을 확인하고 승인합니다.
  3. 격리된 리소스 템플릿으로 what-if를 다시 실행하고, 세 가지 신규 리소스만 표시되는지 검토합니다.
  4. 미리보기 검토 전에는 Azure에 리소스를 적용하지 않습니다.
