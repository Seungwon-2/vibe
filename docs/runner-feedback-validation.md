## 2026-11-16 후속 확인

- 사용자가 배포된 메뉴 UI 확인을 완료했다고 알렸다. 유저 랭킹·내 기록·코인 상점·업적 공통 팝업, 제목 크기와 돌아가기 탐색 정비에 대한 확인으로 기록한다. 브라우저 종류·화면 크기는 전달되지 않았으므로 아래 기기별 전체 검증을 완료 처리하지 않는다.
- 메뉴 UI 배포: `bba90b8`, `9effbe7`, [GitHub Actions 성공](https://github.com/Seungwon-2/vibe/actions/runs/43812625835). 관련 테스트 32개와 빌드·린트 통과. 실서비스 HTTP 200 및 최신 JS/CSS 반영 확인.
- Entra 로그인, SWA 관리형 API, Cosmos DB 개인 기록과 사용자별 최고 기록 랭킹은 현재 배포되어 있다. 아래 과거 로컬 검증 결과와 현재 클라우드 운영 상태를 구분한다.
- 게임 화면/HUD 개편은 사용자가 별도 정리 후 요청하기로 한 상태다. 메뉴 확인을 게임 화면 수정이나 네 테마·장시간 성능 검증 완료로 확대하지 않는다.

## 검증 요약

### 러닝 화면 후속 점검 (2026-11-16)

- 외부 헤더/HUD를 단일 16:9 게임 화면 안으로 통합했다. 패시브 안내와 일시정지 메뉴에서 기능을 확인하며, 고정 효과 슬롯은 화면 높이를 변경하지 않는다.
- 격리 Edge 헤드리스 프로필에서 1366×768, 1920×1080, 915×412, 640×360 뷰포트를 확인했다. 가로·세로 페이지 스크롤 없음, HUD/캔버스 너비 일치, 효과 3개 동시 표시 전후 높이 동일. HUD 높이는 데스크톱 89px, 모바일 가로 60px이다.
- 네 테마 원경은 테스트 장면의 시각 확인만 수행했다. 실제 네 코스 완주나 실기기 터치·장시간 프로파일은 여전히 별도 검증 항목이다.
- 새 테스트 프로필의 스토리 자동 저장에서 기존 Infinity 검증 오류를 발견·수정했다. 스토리 시작/일시정지/새로고침/이어하기에서 경고 없이 거리 복원을 확인했다. 무제한 시간의 JSON 왕복과 재개 진행, 무한 모드 비정상 타이머 거부에 회귀 테스트를 추가했다.

## 알려진 운영 범위와 릴리스 판단

- 개인 런 기록·공유 랭킹은 Cosmos DB와 연결되어 있다. 코인 지갑 및 기타 로컬 진행 데이터까지 서버에 동기화된 것으로 간주하지 않는다.
- 앱은 Azure에 이미 배포되었으며 메뉴 UI는 사용자가 확인했다. 이 문서는 남은 회귀 검증의 범위를 함께 기록한다.
- 수동 브라우저/기기·장시간 플레이 검증이 남아 있어 **전체 회귀 점검 완료로는 처리하지 않는다.** 다른 회사 계정의 종료 기록 저장·본인 기록 격리·랭킹 조회도 후속 통합 확인 항목이다.
- 게임 JS 번들 크기 경고가 있으나 빌드는 성공합니다. 성능 최종 판단은 대상 브라우저 프로파일링 후 내려야 합니다.

## 캐릭터 에셋 확장 메모

현재 선택 화면은 캐릭터 카탈로그에서 사용 가능한 캐릭터를 렌더링합니다. 새 캐릭터는 카탈로그 항목과 모션/초상화/패시브 메타데이터를 등록하면 카드·패시브 설명·하단 러닝 프리뷰 목록에 따라 배치됩니다. 현재 5명의 원본 프레임은 이 점검에서 수정하지 않았습니다. 이후 에셋 추가 작업에서 사용자가 프레임을 교체하고 카탈로그에 새 캐릭터를 추가할 수 있게 두었습니다.
