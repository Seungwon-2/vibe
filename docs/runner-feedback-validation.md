# Stella Runner — 사용자 피드백 회귀 점검

**상태: 로컬 QA 진행 중 · 배포 승인 아님**  
점검 기준일: 2026-11-13  
대상: `project02` 브랜치의 현재 작업 트리

## 검증 요약

현재 코드 기준 자동 검증은 모두 통과했습니다. 기존 브라우저에서의 수동 플레이, 전체 테마별 장애물 실주행, 장시간 프레임 타임 확인은 이번 점검 세션에서 실행할 브라우저를 사용할 수 없어 미완료입니다. 따라서 아래의 수동 확인 항목이 끝나기 전에는 릴리스 완료로 보지 않습니다.

| 명령 | 결과 |
| --- | --- |
| `npm run test` | 통과 — 53개 파일, 282개 테스트 |
| `npm run typecheck` | 통과 |
| `npm run lint` | 통과 |
| `npm run build` | 통과 — 번들 크기 경고는 남음 |
| `npm run assets:validate` | 통과 — 플레이 가능 캐릭터 5명, 각 아틀라스 60프레임 |

빌드는 성공하지만 Vite가 큰 청크 경고를 냅니다(게임 화면 청크 약 1.315MB, 앱 청크 약 599KB). 현재는 기능 회귀가 확인되지 않았고, 코드 분할/청크 최적화는 별도 작업입니다.

## 피드백 20개 상태

상태 뜻: **자동 확인**은 테스트·정적 검증 증거가 있음, **수동 재확인 필요**는 수정 이력 또는 자동 검증은 있으나 현재 빌드의 실제 브라우저 체감 확인이 남음.

| 2 | 로그아웃 상태에서 로그인 버튼만 보여야 함 | **수정 확인됨** — 로그인 흐름 배포 후 사용자가 확인. P0 회귀 테스트 통과. |

## 알려진 운영 범위와 릴리스 판단

- 랭킹·기록·코인 지갑은 현재 브라우저 로컬 범위입니다. Azure Cosmos DB 공유 랭킹은 연결되지 않았습니다.
- 이 문서는 현재 로컬 코드의 검증 상태이며 배포 성공이나 배포 준비 완료를 뜻하지 않습니다.
- 모든 자동 검증은 통과했지만 수동 브라우저/기기 확인이 남아 있어 **이번 점검의 결정은 “배포 보류, 로컬 수동 QA 대기”**입니다.
- 게임 JS 번들 크기 경고가 있으나 빌드는 성공합니다. 성능 최종 판단은 대상 브라우저 프로파일링 후 내려야 합니다.

## 캐릭터 에셋 확장 메모

현재 선택 화면은 캐릭터 카탈로그에서 사용 가능한 캐릭터를 렌더링합니다. 새 캐릭터는 카탈로그 항목과 모션/초상화/패시브 메타데이터를 등록하면 카드·패시브 설명·하단 러닝 프리뷰 목록에 따라 배치됩니다. 현재 5명의 원본 프레임은 이 점검에서 수정하지 않았습니다. 이후 에셋 추가 작업에서 사용자가 프레임을 교체하고 카탈로그에 새 캐릭터를 추가할 수 있게 두었습니다.
