직원 이용 안내

회사 계정으로 로그인해 캐릭터를 고르고, 점프와 슬라이딩으로 별빛 코스를 달려 보세요. 이 파일럿 버전은 게임 플레이와 브라우저 저장을 확인하기 위한 테스트 배포입니다.

스텔라 러너 열기 이번 버전 변경 사항

시작하기

  1. 위의 앱 링크를 열고 회사 계정으로 로그인을 선택합니다. 회사 Microsoft Entra 계정으로 인증합니다.
  2. 메뉴의 계정 영역에서 표시 이름과 계정 식별 정보를 확인할 수 있습니다. 이 영역의 로그아웃 버튼으로 세션을 종료합니다.
  3. 달리기 시작을 누른 뒤 모드를 고르고 캐릭터를 선택합니다. 스토리 모드라면 플레이할 수 있는 코스를 선택합니다.
  4. 첫 런 안내에서 조작법과 아이템, 선택한 캐릭터의 패시브를 확인한 다음 시작합니다. 안내서는 일시정지 화면에서도 다시 열 수 있습니다.

조작법

점프 · 이단 점프

Space 또는 ↑를 눌러 점프합니다. 공중에서 한 번 더 누르면 이단 점프합니다.

슬라이딩

↓를 누르고 있는 동안 슬라이딩합니다. 터치 기기에서는 화면의 점프·슬라이딩 버튼을 사용합니다.

일시정지

P 또는 게임 화면의 일시정지 버튼을 누릅니다. 정지 화면에서 계속하기, 안내서, 사운드 설정 또는 나가기를 선택할 수 있습니다.

가로 화면

모바일에서는 가로 방향으로 플레이하는 것을 권장합니다. 세로 화면에서는 조작이 제한되거나 회전 안내가 표시될 수 있습니다.

모드와 아이템

끝없는 달리기

제한 시간 안에 최대 거리에 도전합니다. 게이트를 통과하면 시간이 추가되고, 장애물 충돌은 생명과 시간에 영향을 줍니다.

스토리 스테이지

테마별 고정 코스를 골인 지점까지 완주합니다. 생명은 스테이지마다 주어지며, 코스의 시간 아이템은 잠시 속도를 높입니다.

코인

런에서 모은 코인은 런이 끝날 때 한 번 지갑에 적립됩니다. 브라우저 저장이 초기화되면 지갑도 복구할 수 없습니다.

속도 부스트 · 거대화

번개 부스트는 짧은 시간 달리기 속도를 높입니다. 거대화는 몸집과 속도를 높이고 일반 장애물을 무시하지만, 낭떠러지는 피해야 합니다.

캐릭터마다 패시브가 다릅니다. 캐릭터 선택 화면과 런 안내서에서 능력 이름과 효과를 확인하세요.

기록과 저장 범위

현재 기록은 로그인 계정이나 Azure에 연결되지 않습니다. 개인 기록·로컬 랭킹·코인 지갑·해금 진행·이어하기 데이터는 이 브라우저 프로필의 저장소에 보관됩니다. 회사 계정별로 분리되거나 다른 기기와 동기화되지 않으며, 같은 브라우저 프로필을 사용하는 사람은 해당 데이터를 볼 수 있습니다. 브라우저 데이터를 지우거나 다른 프로필·기기를 사용하면 이어지지 않습니다.
  • 화면의 “이 브라우저 기록”은 이 브라우저에 저장된 기록입니다. 다른 직원의 최고 기록을 보는 통합 온라인 랭킹은 아직 제공하지 않습니다.
  • 기존 브라우저 기록은 배포 전후 자동 이관되지 않습니다. 새로 로그인해도 기존 로컬 기록은 그대로 브라우저에만 남습니다.
  • 진행 중 탭을 닫았다가 같은 브라우저 프로필에서 돌아오면 이어하기를 선택할 수 있습니다. 저장된 런은 7일 후 만료됩니다. 새로 시작을 확정하면 기존 이어하기 런과 그 런에서 아직 정산되지 않은 코인은 폐기됩니다.
  • 브라우저 저장이 차단되거나 저장 공간이 부족하면 런은 계속할 수 있지만 저장되지 않을 수 있습니다.

문제가 생겼을 때

  • 로그인 화면이 돌아오지 않으면 앱 주소를 다시 열어 회사 계정 로그인을 시도하고, 조직 계정 선택 화면에서 회사 계정을 선택합니다.
  • 저장된 런이나 기록이 보이지 않으면 이전에 사용한 브라우저와 프로필인지 확인합니다. 시크릿 창이나 다른 기기에는 로컬 데이터가 공유되지 않습니다.
  • 화면·조작 오류는 발생한 화면과 재현 순서를 담당자에게 알려 주세요. 비밀번호, 인증 코드, 토큰, 계정 화면 캡처는 보내지 마세요.
