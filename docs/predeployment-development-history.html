DEVELOPMENT JOURNEY · 2026

아이디어에서 배포 준비까지

코딩 경험이 많지 않은 상태에서 요구사항 인터뷰, 단계별 계획, 작은 실행 단위의 구현과 플레이 피드백을 반복해 Stella Runner를 만들었습니다.

제작 방식: grill-me로 결정할 사항을 하나씩 확정하고, memory-plan으로 계획을 파일화한 뒤, memory-execute로 현재 작업을 순차 실행했습니다. 실제 플레이에서 발견한 문제는 다시 계획과 수정 작업으로 연결했습니다.

  1. 2026 · 10 · 21

    플랫포머 아이디어와 첫 게임 설계

    Azure 사내 로그인과 랭킹을 염두에 둔 React 게임 아이디어에서 출발했습니다. 월드·스테이지·보스·체크포인트를 포함한 플랫포머 계획과 오리지널 캐릭터 구상을 정리했습니다.

    초기 기획메모리 기반 계획

  2. 2026 · 10 · 26–27

    러닝 액션으로 방향 전환

    플랫포머 요소를 우선 보류하고, 자동으로 달리며 점프·슬라이딩으로 장애물을 피하는 게임으로 재정의했습니다. 90초 무한 런, 거리·코인 기록, 4개 테마, 보너스 구간과 모바일 입력을 설계했습니다.

    • Rin의 통합 동작 시트 기준과 다른 캐릭터 자산 구조 정리
    • 캐릭터 선택·게임 화면·테마 코스의 반복 개선
    • 낭떠러지, 튜토리얼, 테마별 오브젝트와 충돌 판정 정비

  3. 2026 · 10 · 29–30

    오디오·타이틀·화면 구성

    테마 음악과 효과음 작업을 진행하고, Stella Runner 타이틀 화면과 배경 자산을 연결했습니다. 반응형 화면에서 카드·캐릭터·게임 뷰포트가 잘리거나 지나치게 작아지는 문제를 실제 캡처 피드백에 맞춰 조정했습니다.

    테마 음악캐릭터 선택화면 비율

  4. 2026 · 10 · 31

    스토리 코스와 완주 감각

    스토리 모드의 네 테마에 서로 다른 고정 장애물 시퀀스를 마련했습니다. 각 코스 끝에 아치·결승선·GOAL 표식을 두고 통과 후 승리 포즈를 보여줘 완주 지점을 분명히 했습니다.

  5. 2026 · 11 · 2

    난이도·아이템·장애물 도전

    무한 코스의 코인·장애물 밀도를 높이고, 거대화 아이템을 코인과 시각적으로 구분했습니다. 메리의 자석 효과, 2단 점프를 요구하는 높은 장벽·넓은 함정 도전도 조정했습니다.

    • 스토리 코스는 안전 경로와 고정 배치를 보존
    • 무한 모드는 웨이브 빈도와 후반 난이도를 올리는 방향
    • 장애물 안내는 첫 등장에 집중하고 오브젝트 겹침을 예방

  6. 2026 · 11 · 3

    공통 UI와 배포 전 품질 점검

    모드별 HUD 위치를 통일하고 화면 프레임과 콘텐츠 폭을 맞췄습니다. 무한 모드의 생명 소진에도 탈락 포즈를 넣고, 캐릭터 해금·상점 효과 표시를 다듬었습니다. 이 날짜 기록은 당시의 배포 전 상태입니다.

    당시 상태 (11월 3일): Entra 로그인과 Azure 배포는 아직 실행하지 않았습니다. 이후 배포 준비와 실제 배포는 아래 11월 11–12일 기록에서 확인할 수 있습니다.

  7. 2026 · 11 · 11–12

    회사 계정 로그인과 파일럿 배포

    전용 Static Web App을 연결하고 GitHub Actions로 project02 브랜치의 프런트엔드를 배포했습니다. 단일 회사 테넌트 Entra 로그인, 메뉴의 계정 정보와 로그아웃을 확인했으며, 사용자가 실제 배포본의 로그인과 플레이 흐름을 확인했습니다.

    • 배포 주소: 스텔라 러너 열기
    • 확인한 배포: 커밋 0a475c116073c17cb75a28dd47f8cd815820fbe4, GitHub Actions 실행 43191305221 성공
    • 로그인에 Graph 추가 권한이나 API scope는 요청하지 않습니다. 배포된 런 기록은 Azure/Cosmos에 전송되지 않습니다.
    저장 범위: 기록·지갑·해금·이어하기는 로그인 계정과 분리된 브라우저 프로필 로컬 저장입니다. 같은 프로필을 사용하는 사람은 데이터를 볼 수 있고, 온라인 통합 랭킹은 아직 연결하지 않았습니다.

사용자 피드백이 만든 개선

점프 불가 발판, 화면 밖 추락, 낙하 애니메이션 중단, 슬라이딩 판정, 스프라이트 잘림, 캐릭터 크기 차이, 화면비와 스크롤 같은 문제를 직접 플레이하고 캡처로 전달했습니다. 이를 바탕으로 충돌·표시·애니메이션을 분리해 고쳤습니다.
