# 캐릭터 선택창 5×3 배열과 상세 미리보기

- 날짜 2026-11-18
- 상태 확정
- 작업 브랜치 `project02`

## 사용자 결정

- 현행 선택창의 배경색, 배경 이미지와 밝은 스타일을 유지한다. 첨부 시안에서 왼쪽 5열×3행 목록과 오른쪽 상세 패널 배치를 적용한다.
- 게임에 등록된 5명을 표시하고 나머지 10칸은 빈 슬롯으로 둔다. 첨부 폴더의 15장 중 현행 캐릭터에 해당하는 5장을 선택창 이미지로 사용한다.
- 오른쪽 패널은 선택한 캐릭터의 일러스트, 이름, 패시브 정보를 표시한다.

## 이미지 적용

원본 폴더는 `assets/character/reference/stellive_sd_masters_512x512/`이다. 아래 5장이 각각 512×512이고 실제로 투명 영역이 있음을 파일에서 확인했다.

| 기존 캐릭터 ID | 표시 이름 | 원본 파일 |
| --- | --- | --- |
| `player-default` | 아오쿠모 린 | `01_aokumo_rin_master.png` |
| `hanayo-hiyori` | 하나요 히요리 | `06_hanayo_hiyori_master.png` |
| `tokino-mary` | 토키노 메리 | `08_tokino_merry_master.png` |
| `goth-student` | 시즈키 토아 | `02_shizuki_toa_master.png` |
| `cogane-rang` | 코가네 랑 | `07_kogane_rang_master.png` |

- 얼굴 카드는 각 이미지의 얼굴·어깨를 중심으로 잘라 보여주고, 오른쪽 패널에는 같은 원본의 전신을 정적으로 표시한다. 캐릭터마다 투명 여백과 얼굴 위치가 달라 카드 크롭과 전신 여백을 각각 맞춘다.
- 사용자가 지적한 머리카락·옷 사이의 흰 여백을 다섯 캐릭터의 얼굴 카드와 전신 미리보기에서 확인한다. 투명 영역이 있어도 원본에 불투명한 흰 픽셀이 남아 있을 수 있다. 흰 의상·머리카락 디테일도 포함되어 있으므로 흰색을 일괄 삭제하지 않는다.
- 틈의 흰색이 배경에서 눈에 띄고 원본 손상 없이 정리하기 어렵다면 오른쪽 전신 일러스트 영역에 흰색 바탕을 공통 적용한다. 얼굴 카드에서도 문제가 보이면 카드의 이미지 영역까지 같은 흰색으로 맞춘다. 화면 전체 배경과 상세 패널의 이름·패시브 영역에는 현행 색감을 적용한다. 구현 검증 때 다섯 캐릭터의 확대·축소 상태를 모두 비교해 적용 범위를 결정한다.
- 선택창 전용 표시 자산으로 연결한다. 현재 캐릭터 ID, 게임 스프라이트, 결과 화면 일러스트에 쓰이는 기존 URL은 유지한다.

## 기존 화면을 바탕으로 정한 동작

- 현재 표시 순서인 린 → 히요리 → 메리 → 토아 → 랑으로 첫 행을 채운다. 빈 슬롯은 차후 캐릭터 추가를 위한 비대화형 칸으로 표시한다.
- 왼쪽 카드는 얼굴과 이름, 선택·잠김 상태를 표시한다. 잠긴 캐릭터의 기존 해금 조건과 선택 제한을 유지한다. 빈 슬롯과 잠긴 카드는 시작 대상이 될 수 없다.
- 오른쪽에는 기존 패시브 아이콘·이름·설명과 시작 버튼을 배치한다. 시안의 예시 능력치 막대는 도입하지 않는다. 선택창 아래 전체 달리기 미리보기는 오른쪽 전신 미리보기로 대체한다.
- 충분한 가로 폭에서는 좌우 배치, 좁은 세로 화면에서는 목록 아래 상세 패널을 둔다. 실제 열 수에 맞춰 방향키를 처리하고, 빈 슬롯·잠긴 카드는 건너뛴다. Enter로 카드 선택을 유지한다.
- 타이틀로 이동과 코인 상점은 왼쪽 아래에 둔다. 시작 버튼은 무한 모드에서 런 시작, 스토리 모드에서 스테이지 선택으로 이어지는 기존 동작을 따른다.
