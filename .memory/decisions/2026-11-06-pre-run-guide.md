# Decisions: Pre-Run Guide

- Date: 2026-11-06
- Status: Confirmed

## D01. First-run display
- **Chosen**: Show the guide automatically before the first run in this browser, then remember that it was seen.
- **Rationale**: Explain the controls and current gameplay before play without interrupting later runs.

## D02. Reopening the guide
- **Chosen**: Add a guide/manual action to the pause dialog so players can review it at any time.
- **Rationale**: Players can revisit the instructions without restarting a run.

## D03. Guide content
- **Chosen**: Explain keyboard and touch controls, all current items, and the selected character's passive ability.
- **Rationale**: Players need both shared gameplay rules and the ability that applies to their selected character.
- **Details**: Describe mode-specific time-item effects accurately; include jump, double jump, slide, coins, time items, speed boost, giant effect, and the selected character passive.

## D04. Start and return behavior
- **Chosen**: The first-run guide's start action begins the existing three-second countdown. Opening the guide from pause and closing it returns to the paused run.
- **Rationale**: The initial guide naturally continues into play, while a manual review must not resume gameplay unexpectedly.
