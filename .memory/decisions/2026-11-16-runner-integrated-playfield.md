# 러닝 플레이 화면 통합

## 확정한 방향

- 사용자 제공 쿠키런 화면의 정보 배치와 높은 플레이 영역 비중을 참고한다. 기존 캐릭터·테마 자산을 유지한다.
- 별도 캐릭터명/나가기 헤더를 제거하고 16:9 플레이 화면을 브라우저 안에서 최대한 확대한다. 가로세로 비율이 다른 화면의 가장자리 여백은 허용하되 늘이기나 코스 잘라내기로 채우지 않는다.
- HUD는 게임 안쪽 상단에 얇은 반투명 영역으로 표시한다. 생명, 시간/스토리 진행률, 거리, 코인, 패시브 아이콘, 일시정지를 같은 위치에 둔다.
- 패시브 상세 설명은 아이콘에서 여는 안내서에 유지한다. 안내서를 열면 일시정지하며 닫으면 일시정지 메뉴로 돌아온다. 나가기는 일시정지 메뉴에서 제공한다.
- 거대화·2.5배 속도·스토리 속도 효과는 고정 슬롯에 아이콘과 남은 시간을 표시한다. 효과 발생·종료가 HUD/플레이 화면 높이를 바꾸지 않는다.
- 원본 960×540 물리 좌표와 판정·스폰 간격·타이머는 유지한다. 카메라만 1.05배 확대하고 캐릭터와 바닥 기준 위치를 고정해 원래 전방 시야의 90% 이상을 보장한다.
- 네 테마의 옅은 원경 장식을 기존 캐시 텍스처에 추가한다. 오브젝트 수·코인 경제·장애물 수는 화면 채우기를 위해 변경하지 않는다.

## 검증 범위

- 로컬 Edge 격리 프로필에서 1366×768, 1920×1080, 915×412, 640×360 뷰포트의 스크롤 없음과 HUD/캔버스 일치, 동시 효과 3개 발생 전후 높이 고정을 확인한다.
- 네 테마 배경은 일시정지한 테스트 장면에서 시각 확인한다. 실제 전 코스 완주·실기기 터치·장시간 성능 검증을 대체하지 않는다.
- 실제 스토리 시작/일시정지/새로고침/이어하기를 확인한다.

## 함께 발견한 저장 결함

- 새 격리 프로필에서도 스토리 체크포인트 저장 실패가 재현되었다. 시뮬레이션의 무제한 시간 `Infinity`가 저장 검증에서 거부되고 JSON에서는 `null`이 되는 것이 원인이다.
- 활성 스토리 저장에만 `Infinity`를 허용하고 JSON의 `null`을 읽을 때 복원한다. 무한 모드의 비정상 타이머는 계속 거부하며 물리·시간 규칙은 변경하지 않는다.
