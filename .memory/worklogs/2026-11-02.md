# 작업일지 — 2026-11-02

## 작업 범위

`runner-polish-predeploy` 계획에 따라 업적, 스테이지 선택 화면, 장애물 판정, 거대화 연출, 엔딩 애니메이션을 정비하고 로컬 배포 전 점검을 진행했다. 오디오 교체 파일은 사용자가 직접 제공하기로 해 현재 파일은 유지하고 해당 작업은 대기 상태로 남겼다.

## 반영한 변경

- 반복되던 업적을 러너 전체 달성·스토리 전체 완주 업적으로 정리했다.
- 스토리 스테이지 선택을 화면 높이에 맞춘 2×2 고정 배치로 바꾸고, 작은 화면에서 버튼과 설명이 줄바꿈되도록 조정했다.
- 천장 장애물 충돌 구역을 점프 높이 전체로 늘렸다. 공중에서는 충돌하고 지면 슬라이드 중에는 안전하게 통과한다. 그림과 안내 위치는 유지했다.
- 거대화 상태에서도 점프·이단 점프·하강·슬라이드·피격 애니메이션이 각 상태에 맞게 재생되도록 했다. 거대화 오라는 선택 캐릭터의 상징색을 사용해 은은하게 낮췄다.
- 승리·게임오버 애니메이션은 캐릭터별 시트 FPS를 사용하고, 한 번 재생한 뒤 마지막 포즈를 유지한다.

## 배포 준비 확인

- 저장소에는 `.env.example`만 있고 실제 환경 파일은 없다. Entra/API 설정은 `VITE_ENTRA_TENANT_ID`, `VITE_ENTRA_CLIENT_ID`, `VITE_ENTRA_API_SCOPE`, `VITE_API_BASE_URL` 예시 변수로만 문서화돼 있다.
- 코드와 `package.json`에서 MSAL/Entra 구현을 찾지 못했다. Azure 호스팅·배포 워크플로 설정도 저장소에서 찾지 못했다.
- 따라서 현 시점은 Azure 배포 준비 완료가 아니다. Entra 로그인 구현, 실제 Azure 배포 설정·리디렉션 URI, 환경 설정, 백엔드/API 연결, 실패 테스트와 lint 정리가 남았다. 배포는 하지 않았다.
