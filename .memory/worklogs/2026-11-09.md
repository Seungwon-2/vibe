# 작업일지 — 2026-11-09

## Azure Functions API 및 Cosmos 데이터 계층

- Entra 단일 테넌트 액세스 토큰을 검증하고, 토큰에서 사용자 식별자를 만들어 API 요청에 연결했습니다. 표시 이름은 검증된 `name` 클레임을 쓰고 없으면 `Runner`로 처리합니다.
- Azure Functions에 프로필 조회·장착 변경, 런 저장, 본인 기록 페이지 조회, 본인 최고 기록, 공개 랭킹 API를 구성했습니다.
- Cosmos 데이터는 플레이어별 파티션으로 분리했습니다. 전체 런 기록은 소유자만 읽고, 공개 랭킹은 플레이어별 최고 Endless 기록 투영 한 건만 사용합니다. Story 기록은 공개 랭킹에서 제외합니다.
- 런 제출·보상 지급은 같은 `runId` 재시도에 중복 처리되지 않도록 구성했습니다. 프로필·런·최고 기록 변경은 사용자 파티션 내 트랜잭션 배치로 저장합니다.
- Cosmos 엔드포인트와 데이터베이스·컨테이너 설정은 환경 변수로 받으며, 리소스나 컨테이너를 자동 생성하지 않습니다. 공유 Maze Rescue 데이터 컨테이너를 변경하지 않습니다.
- 클라이언트 런 제출 모델과 API 응답 사이의 `runId` → 화면용 `id` 변환, 동일 런 재시도 시 식별자 유지, 잘못된 날짜 검증을 테스트했습니다.
