### Azure 배포 준비 P01-T01: Entra SPA 로그인과 인증 API 연결

- MSAL SPA 인증을 추가해 설정된 단일 Entra 테넌트로 로그인하도록 구성했습니다. 브라우저에 클라이언트 시크릿을 두지 않고, Microsoft Graph 권한도 요청하지 않습니다.
- Entra 설정이 없는 로컬 개발에서는 기존 브라우저 로컬 저장소와 게임 흐름을 유지합니다. 배포 환경에서 로그인하지 않은 사용자는 클라우드 게임과 기록 화면에 진입할 수 없도록 했습니다.
- 인증 토큰을 전달하는 `AuthenticatedRunGateway`와 공통 기록 DTO 계약을 추가했습니다. 개인 기록, 개인 최고 기록, 공개 랭킹 조회 및 런 결과 제출 경로를 준비했습니다.
- 메뉴의 회사 계정 로그인·로그아웃과 클라우드 랭킹 명칭을 연결했습니다. 공개 랭킹은 계정 식별자 대신 서버가 검증한 표시 이름과 캐릭터를 사용하도록 계약을 정리했습니다.
- Phaser 게임 화면을 지연 로딩하도록 분리해 초기 앱 번들을 줄였습니다.
