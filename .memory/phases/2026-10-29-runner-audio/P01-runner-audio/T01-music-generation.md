# Task: T01 Generate Original Music

## Status: deferred

## Goal

Create a reproducible, original, piano-led soundtrack as local WAV files: one menu loop and one loop for each of the four runner biomes. The files must play offline and use no third-party recording, melody, soundfont, or sample.

## Decision Summary

- Generate playable files with a deterministic Node.js script using built-in modules only; output 32 kHz, mono, 16-bit PCM WAV.
- Pokémon Diamond/Pearl road music, including Route 209, is a high-level mood reference for adventurous road-game energy and memorable melodies. Write all melody, harmony, and arrangements originally; do not reproduce or closely imitate any specific tune.

## Implementation

### I01. Compose original track data and render loopable WAV files

- Related Files:
  - `scripts/audio/runnerMusicData.mjs` :: `RUNNER_MUSIC_TRACKS`, `MusicTrackDefinition`, `NoteEvent` — deterministic composition data for five tracks; new
  - `scripts/audio/audioRenderer.mjs` :: `renderTrackToPcm`, `encodePcmWav`, `writeWavFile` — pure synthesis/rendering primitives; new
  - `scripts/generate-runner-music.mjs` :: `generateRunnerMusic`, `main` — writes tracks or checks outputs; new
  - `public/audio/music/menu.wav` — main menu/selection/ranking/result loop; generated
  - `public/audio/music/dawn-city.wav` — dawn city loop; generated
  - `public/audio/music/moonlit-forest.wav` — moonlit forest loop; generated
  - `public/audio/music/crystal-mine.wav` — crystal mine loop; generated
  - `public/audio/music/cloud-skyway.wav` — cloud skyway loop; generated
  - `scripts/audio/audioRenderer.test.mjs` — WAV header, determinism, clipping, and seam tests; new
  - `package.json` :: `scripts` — add `audio:music:generate` and `audio:music:check`; modify
- Details:
  - Define `NoteEvent` fields as `{ startBeat: number; durationBeats: number; midiNote: number; velocity: number }`.
  - Define `MusicTrackDefinition` fields as `{ id: 'menu' | 'dawn-city' | 'moonlit-forest' | 'crystal-mine' | 'cloud-skyway'; bpm: number; beatsPerBar: 4; bars: number; melody: readonly NoteEvent[]; accompaniment: readonly NoteEvent[]; bass: readonly NoteEvent[]; seed: number }`.
  - Export `RUNNER_MUSIC_TRACKS: Readonly<Record<MusicTrackDefinition['id'], MusicTrackDefinition>>`; make all note data deterministic and validate MIDI pitch, beat positions, positive durations, and velocity `[0, 1]` before rendering.
  - Export signatures `renderTrackToPcm(track: MusicTrackDefinition, sampleRate?: number): Float32Array`, `encodePcmWav(samples: Float32Array, sampleRate: number): Buffer`, and `writeWavFile(filePath: string, samples: Float32Array, sampleRate: number): void`.
  - Generate a piano-like tone from an original synthesized voice with a short hammer-style transient, slightly inharmonic decaying partials, velocity-dependent attack, and a natural release. Keep the piano the lead. Use only quiet synthesized accompaniment layers for theme identity; avoid an electronic lead or third-party sample/soundfont.
  - Give the five tracks distinct original motifs and accompaniment colors that fit menu, dawn city, moonlit forest, crystal mine, and cloud skyway. Keep a bright fairytale mood and a recognizable sense of exploration. Do not copy Route 209 or any Pokémon melody, harmony progression, recording, or exact arrangement.
  - Target 60–90 seconds per loop (within the confirmed 60–120 second range). Use a bar-aligned duration and a short deterministic tail/crossfade in the renderer so the final sample joins the first without a pop; do not add silence at the seam.
  - Encode 32 kHz, mono, signed 16-bit little-endian PCM WAV with correct RIFF/data lengths. Clamp before conversion; fail the check command on clipping, malformed header, duration outside 60–120s, or non-deterministic output.
  - `npm run audio:music:generate` runs `node scripts/generate-runner-music.mjs`; `npm run audio:music:check` runs `node scripts/generate-runner-music.mjs --check` and verifies generated bytes match a fresh deterministic render without overwriting files.
  - The renderer is deliberately a piano-like synthesis, not a recorded grand piano. Keep the five files easy to audition directly in a local media player so the user can judge timbre and style before the rest of the audio integration is considered complete.
  - Keep scripts and generated WAVs as project assets; no external URL is required at runtime or during regeneration.
