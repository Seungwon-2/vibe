# 바람과 빛의 러너

React와 Phaser로 만든 로컬 플레이용 2D 러닝 액션 게임입니다. 캐릭터를 고르고, 점프와 슬라이딩으로 장애물을 피하면서 제한시간 동안 달린 거리를 기록합니다. 현재 플레이와 기록 저장에는 로그인이나 네트워크 연결이 필요하지 않습니다.

## 개발 환경 실행

- Node.js `>=22.12.0 <25`
- 패키지 설치: `npm ci`
- 개발 서버: `npm run dev`
- 브라우저에서 Vite가 출력한 로컬 주소를 엽니다. 보통 `http://localhost:5173/`입니다.

검증 명령:

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

## 조작

게임은 가로 화면을 기준으로 합니다. 세로 화면에서는 진행 중인 런을 일시정지하고 기기를 가로로 돌리라는 안내를 표시합니다.

- `Space` 또는 `↑`: 점프. 공중에서 한 번 더 누르면 2단 점프합니다.
- `↓`: 누르고 있는 동안 슬라이딩합니다. 공중에서는 슬라이딩할 수 없습니다.
- `P`: 일시정지 또는 이어하기.
- 터치 기기: 화면 양쪽 아래의 점프·슬라이딩 버튼을 사용합니다. 슬라이딩은 버튼을 누르고 있는 동안 유지됩니다.

## 런 규칙

- 카운트다운 후 90초 런이 시작됩니다. 보너스를 포함한 제한시간은 최대 120초입니다.
- 코인은 접촉 시 자동으로 수집되며, 기록 동률을 가르는 보조 기준입니다.
- 시간 아이템은 3초를 추가합니다. Aokumo Rin은 패시브로 1초를 더 얻습니다.
- 2,500m, 5,000m, 7,500m 게이트를 통과하면 각각 20초를 한 번씩 추가합니다. 제한시간은 120초를 넘지 않습니다.
- 장애물 충돌은 5초를 차감하고 기본 1.2초 동안 피격·보호 상태가 됩니다. Tokino Mary는 여기에 250ms가 더해져 총 1.45초 동안 보호됩니다.
- 달리기 속도는 시작 시 초당 250 유닛이며 첫 90초 동안 초당 325 유닛까지 점진적으로 증가합니다. 게임 내 거리는 미터로 표시합니다.
- 코스 테마는 새벽 도심(0m), 달빛 숲길(2,500m), 수정 광산(5,000m), 구름 위 하늘길(7,500m) 순서입니다.

캐릭터 패시브는 모두 중앙 설정에서 관리합니다:

| 캐릭터 | 패시브 |
| --- | --- |
| Aokumo Rin | 시간 아이템 +1초 |
| Shizuki Toa | 슬라이딩 해제 유예 150ms |
| Cogane Rang | 2단 점프 힘 +8% |
| Hanayo Hiyori | 아이템 수집 범위 +20px |
| Tokino Mary | 기본 충돌 보호에 +250ms (총 1.45초) |

현재 캐릭터 선택창에서는 Rin, Hiyori, Mary를 선택할 수 있습니다. Toa와 Rang은 대응 스프라이트 준비 전까지 비활성 상태로 표시됩니다.

## 로컬 랭킹과 기록 초기화

런 기록은 현재 브라우저의 `localStorage`에 저장됩니다. 상위 10개 런을 거리 내림차순, 코인 내림차순, 완료 시각 오름차순, 기록 ID 순으로 정렬합니다. 결과 화면의 캐릭터별 최고 기록은 통합 랭킹과 별도 저장소를 사용합니다.

개발자 도구 콘솔에서 다음 명령으로 랭킹과 캐릭터별 최고 기록을 각각 삭제할 수 있습니다.

```js
localStorage.removeItem('running-action:records:v1');
localStorage.removeItem('running-action:personal-best:v1');
```

Azure Entra ID 로그인과 서버 통합 랭킹은 아직 연결하지 않았습니다. 현재 동작은 오프라인 로컬 플레이를 위한 것입니다.
